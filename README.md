Night Harvistor

 - Godot 3D Horror game about harvesting crops from corn maze
 - libresprite, obsidian for story, godot for game development
 - Made using GDScript. Problems were encountered such as enemy ai getting stuck but was fixed with tinkering
 - How To Use: If possible I would HIGHLY recommend playing from the windows exe as that is more stable however we also have a release on itch.io: https://smithkay.itch.io/night-harvistor
 - I will admit I used small parts of ai for code snippets due to being new to the engine but I used it twice maybe in the entire program (so less than 5%)
